I don't start from scratch — I start from *someone else's* scratch. I fork projects that fascinate me, break them, understand them, and ship something better. That's how a fork became **DollBloom** — **65⭐ and 3,900+ downloads** strong.

- 🔭 Building **DollBloom** (Material 3 Android music player with YouTube Music support) & **DominatorMusicDesktop** (Next.js web music app)
- 🧬 Fork alchemist — read the code, break the code, become the code
- 🐍 Squeezing Terminal into my workflow — **InstaSnap** is a pure-Python CLI that pulls Instagram sessions on Termux
- ⚡ **action-vps** lets you spin up a temporary Ubuntu VPS on GitHub Actions — *15 forks and counting*
- 🤖 Side quests: LSPosed modules, Telegram userbots, GitHub Actions experiments
- 🎧 Usually coding while testing yet another music player
